# 评测起步工具

`cases.jsonl` 是人工编写的六条冒烟样本，不是独立测试集，不能据此声明模型准确率或泛化能力。

对实际模型/检索输出逐条记录 JSONL，每行需要 `id`、`expected_flow`、`candidates`（按排名排列）。可选 `expected_slots`、`predicted_slots` 与由真实业务结果判定的布尔字段 `task_success`。不要把 Top-1 命中直接填为任务成功。

运行：`python -m evaluation.score predictions.jsonl`。

输出分别统计 Top-1、Top-3、槽位整组完全匹配率及任务成功率，每项标出样本数；没有任务标签时返回 null。该工具只统计已记录的预测，不调用模型，不提供虚构预测或 92% 结果。

正式评测需要扩充口语、多轮、意图切换、拒识与越权样本，去重并冻结独立测试集，记录数据来源、模型、提示和检索版本。安全类样本应另报拒绝情况，不与正常流程命中率混为一项。
